本次更新给分流排除项加上「应用名 / 图标 / 备注」，列表改为按应用分组展示，并支持从流量监控页一键把连接加入排除、自动带上该程序的应用名与图标。

- **排除项元数据**：域名、IP 段、DNS fallback 三类规则都可以填写应用名（必填）、图标与备注。不上传图标时按应用名首字母生成彩色头像；备注显示在条目下方，方便记录「这条是干什么用的」。
- **按应用分组**：三个列表改为按应用名分组展示，同名应用合并成一组，组头显示图标、应用名与条数；未填应用名的旧规则按目标值各自成组排在后面。分页按组计数，一组不会被拆到两页。
- **随时补充信息**：每条规则新增「信息」按钮，可事后补填或修改应用名、图标、备注，只改展示信息，不会动已经生效的分流规则。
- **流量监控一键排除**：进程组头新增「排除」，把该进程下的多个目标一次性加入排除，共用同一个应用名与备注（批量时不再逐条显示目标）；单条连接悬停也可单独排除。域名走域名规则，纯 IP 连接自动转成 CIDR 走 IP 规则。
- **自动识别应用名与图标**：从流量监控页添加时，程序会读取该进程可执行文件的版本信息（ProductName 等）与图标自动预填，取不到时回退到流量页已显示的图标，仍可手动改动或上传自己的图标。

下载附件 `CampusAuth.exe` 即可使用。更新仅替换程序，同目录的账号配置、分流规则与工作流保持不变；已有规则没有应用名，会按目标值各自成组，随时可以点「信息」补上。
