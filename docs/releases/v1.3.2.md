本次更新把 DNS 相关设置独立成标签页，新增按域名/IP 定向指定解析服务器（可选下发到系统），并为流量监控补上连接类型筛选。

- **DNS 设置标签页**：侧边栏新增「DNS设置」（位于「设置」之前），原设置页中的 DNS 服务器卡片整体迁入；服务商预选、自定义 IPv4/IPv6 与保存校验保持不变。
- **定向解析绑定**：可为特定域名（含子域名）、IP 或网段指定解析所用的 DNS 服务器，多规则命中时取最具体的一条；未命中的解析仍走全局 DNS。规则作用于本程序的 A/AAAA 查询（分流规则的 CIDR 前缀、防火墙封禁、hosts 条目）。
- **系统级生效（NRPT）**：定向规则可一键下发到 Windows 名称解析策略表，使浏览器等所有程序对匹配域名改用指定服务器（需管理员权限）；下发记录单独保存，可一键清除，不影响其他来源的策略。
- **流量监控类型筛选**：支持按 6 种连接类型（IPv4/IPv6 直连、WARP 四种组合）筛选，入口有三处——概览流向图、类型筛选条、进程组内的类型标签；每个进程可单独筛选（非空即覆盖全局，点「跟随全局」取消）。筛选偏好随界面偏好保存，重启后保留。
- **筛选可读性修正**：进程组折叠概要里的类型数字改为 12px 加粗等宽，与 10px 的类型名明确区分；类型入口在展开态同样常驻，且按筛选前全量统计，筛中某类后仍可切换其他类型。
- **计数提示**：进程单独筛选时计数显示「可见/总数」；被筛选隐藏的进程给出一行提示与「清除筛选」入口。

下载附件 `CampusAuth.exe` 即可使用。更新仅替换程序，同目录的账号配置、分流规则与工作流保持不变。
