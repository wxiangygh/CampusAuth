本次更新新增 DNS 服务器设置，为分流列表补充分页，并调整 Windows 10 的分流配置查看方式。

- **DNS 服务器设置**：设置页新增阿里云、北京联通、114 DNS、Google、Cloudflare 预选项，支持自定义 IPv4 / IPv6 地址与保存时的格式校验。
- **DNS 生效范围**：分流规则的新域名解析使用保存的 DNS；认证流程的 IPv6 DNS 在下次执行“设置 IPv6 DNS”节点时生效，留空表示自动获取。DNS Fallback 继续使用本地网络的 DNS。
- **分流规则分页**：IP 排除与 DNS Fallback 复用域名排除的分页样式，支持每页 10 / 20 / 50 / 100 条并保存偏好；删除末页记录后自动调整页码。
- **Windows 10 兼容处理**：“当前分流配置”改用应用内弹窗，避开独立子窗口的兼容问题。Windows 11 保留独立窗口，创建报错时回退到应用内查看。
- **错误提示**：读取分流配置失败时显示错误信息；本地页面路径改用标准文件 URI。

下载附件 `CampusAuth.exe` 即可使用。更新仅替换程序，同目录的账号配置、分流规则与工作流保持不变。
